# Viral AI Editor

First prototype of an AI-first video and photo editor.

## Prototype
- Video and photo import with drag and drop
- Browser video preview and timeline
- 9:16, 1:1 and 16:9 output selector
- AI analysis panel and viral potential score
- Editing recommendations for hook, pacing, captions and visual changes
- Voice polish and viral strategy actions
- Responsive dark editor UI

## Product direction
The long-term system should learn editing patterns from properly licensed or explicitly permitted examples, then apply those patterns to a user's own media.

Pipeline:
1. Understand speech and visuals
2. Detect hooks, key moments and low-energy sections
3. Generate an edit decision list
4. Apply cuts, captions, zooms, B-roll and audio decisions
5. Preview and render
6. Learn from approved examples and user feedback

The current UI uses prototype analysis values. No external AI model or rendering backend is connected yet.

## Run
Open index.html in a browser or deploy with GitHub Pages.
